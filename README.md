# Medical Insurance Charges Prediction

## About the Project
This project uses machine learning to estimate medical insurance charges based on customer information such as age, BMI, smoking status, and other demographic factors.

## Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- XGBoost
- SHAP
- Flask
- Docker

## Key Activities
- Performed data cleaning and exploratory data analysis.
- Prepared features for machine learning models.
- Trained and compared multiple regression models.
- Used hyperparameter tuning to improve model performance.
- Applied SHAP to understand the factors influencing predictions.
- Developed a Flask application to generate insurance cost predictions.
- Containerized and deployed the application using Docker and Render.

## Skills
Python, data preprocessing, exploratory data analysis, regression modeling, model evaluation, feature importance, API development, and deployment.

## Disclaimer
This project is for educational purposes only. Predictions are estimates and should not be considered actual insurance quotes or financial advice.
